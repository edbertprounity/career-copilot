# Synthetic student profiles

These records are fictional profiles created for Assessment 1 testing. They represent a synthetic 43007 tutorial cohort of plausible third-year UTS Faculty of Engineering and Information Technology Computing Science students, not real students or a statistical sample.

- `student_profiles.jsonl` contains the confirmed profile facts used by the CV Builder.
- `student_introductions.jsonl` contains the initial plain-English introductions used to test follow-up questions and profile confirmation.
- Every profile uses the same field structure, while projects, skills, work experience and target roles vary deliberately.
- `relevant_current_subjects` lists the subject relevant to this assessment; it is not a complete study-load record. `coursework_highlights` contains selected recent or completed subjects.
- `prerequisite_context` records the synthetic assumption needed for the 43007 test scenario. It is not a verified transcript or enrolment record.
- `skill_evidence` links a listed skill to a project, coursework item or role so that the CV Builder can avoid unsupported skill claims.
- Names, links, organisations and contact details are fictional placeholders. No real student data should be added here.

The profiles include different levels of experience: coursework-only work, AI/NLP projects, data analysis, systems and security experience, and one synthetic UTS IDeA cadetship. Advanced technologies should be treated as evidence from the named project or role rather than as assumed knowledge for every student. The fictional society, showcase, employer and example links must remain marked as synthetic when displayed outside the classroom.
